# 小牛 SDK 插件

小牛 SDK 渠道与功能插件集合，以 UPE 格式打包，用于游戏 SDK 的多渠道集成。

## 项目内容

共包含 34 个插件，涵盖以下类别：

### 渠道 SDK（11 个）
- 阿里（UC）、百度、B站、华为 HMS 4.0
- 金立、酷派、联想、魅族、Oppo
- 奇虎360、VIVO、小米（商用版本）

### 框架 SDK（3 个）
- XNSDK、XSDK、应用宝 YSDK

### 功能插件（11 个）
- 腾讯 Bugly、酷派 DataEye、空渠道
- 华为广告、4399广告联盟、汇量 Mintegral 广告
- Oppo 广告联盟、聚合广告、TalkingData
- 腾讯广点通、穿山甲广告

### 统计与推送插件（4 个）
- 友盟统计、友盟推送、友盟分享、统一实名

### 其他广告插件（2 个）
- Vivo 广告联盟、小米广告联盟

### 工具（3 个）
- Windows 打包工具、macOS 打包工具、全局配置

## 技术栈

- UPE 插件打包格式
- 各渠道 SDK 原生集成

## 说明

插件的具体版本信息详见 `version.txt`。
